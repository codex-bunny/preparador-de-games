# olá, esse é um projeto meu pessoal que visa facilitar a instalação de jogos no linux
## sobre
todos queremos jogar em nossos computadores, mas as vezes ter que baixar arquivo por arquivo fica extremamente chato. esse script em python tenta resolver isso
recentemente, eu experimentei cachyOS e vi que eles tinham um preparador para jogos. eu fiquei facinado e quis fazer o meu
